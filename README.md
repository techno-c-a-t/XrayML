# X-Ray Threat Scanner (Web Release) 🛡️

Автономное веб-приложение для нейросетевого обнаружения скрытых угроз на рентгеновских снимках багажа.  
Инференс выполняется **на 100% на устройстве** через WebGPU / WASM SIMD без отправки данных на сервер.

Разработчик: **Nikitos ([@techno_c_a_t](https://technocat.cc))**

---

## ⚡ Особенности релиза

- **Чистая веб-сборка**: включены только фронтенд-файлы, модель `best.onnx` и сэмплы (общий вес репозитория ~15 МБ).
- **Поддержка GitHub Pages / Static Hosting**: встроен `coi-serviceworker.min.js`, автоматически обеспечивающий Cross-Origin Isolation (`SharedArrayBuffer`) для 8-поточного инференса WebAssembly SIMD на статическом хостинге.
- **Полная автономность**: работает в любом современном браузере.

## 🚀 Запуск локально

```bash
# Python встроенный сервер с поддержкой заголовков изоляции
python3 server.py
```

Откройте в браузере: `http://localhost:8080/`

Или используйте любой статический веб-сервер (Nginx, Caddy, GitHub Pages, Vercel, Cloudflare Pages).
